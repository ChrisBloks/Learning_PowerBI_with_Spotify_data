# Learning_PowerBI_with_Spotify_data
Personal project for learning how to do data visualization using PowerBI using spotify track streaming history

Created the python scripts mostly through vibe coding with Claude and Copilot.
Wanted to create a script to automatically run API calls to spotify to get track lengths, however it seems spotify has a daily API rate limit of 600, and with more than 20000 unique songs played, I've decided to put that idea on hold.

Normally I don't vibe code but I thought I'd try it out in order to write the API call scripts, see what I can learn.
Some notes:
- Claude and Copilot don't necessarily agree on 'the best' code structure
- Both agents love error handling (or alternatively: I really suck at error handling)
- Agent's will sometimes work on bad assumptions (Spotify's web API is often updated, changing call signatures)
